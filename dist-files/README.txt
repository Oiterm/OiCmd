OiCmd — 네트워크 장비 명령어 사전
==================================

시스코 · 주니퍼 · 얼라이드 · 알카텔 장비의 명령어를 하는 일별로 나란히 보고, 다른 벤더 명령어로 바꾸고,
VLAN·포트 설정문을 만들어 주는 프로그램입니다.

 벤더       시스코 IOS/IOS-XE, 주니퍼 Junos(EX, ELS), 얼라이드 AlliedWare Plus, 알카텔 OmniSwitch AOS6 · AOS8
 설치       OiCmd-Setup-버전.exe (관리자 권한 필요 없음, 지금 사용자에게만 설치)
 포터블     OiCmd-버전-portable.zip 을 풀고 oicmd.exe 실행
 저장 위치  내 명령어·확인 표시·설정: %APPDATA%\OiCmd\user.json (바로 전 내용은 user.json.bak)

[명령어 사전]
 - 위쪽 찾기 칸에 하는 일(맥 주소, 트렁크, 백업 …)이나 명령어(sh int status, show vlans …)를 넣습니다. Ctrl+K 로 바로 찾기.
 - 위쪽 오른쪽에서 보여 줄 벤더를 고릅니다(이 PC 에 기억).
 - <포트> <VLAN번호> 처럼 노란 글자는 실제 값으로 바꿔 넣는 자리입니다.
 - [미확인]  기본 명령어는 공식 문서 기준이지만 모델·OS 버전에 따라 다를 수 있습니다. 실제 장비(또는 PNETLab)에서
            쳐 보고 맞으면 눌러서 [✓ 확인됨]으로 바꿔 두세요. 명령어가 바뀌면 다시 미확인이 됩니다.
 - [고치기]  틀리거나 우리 현장에 맞지 않는 명령어는 고쳐 두면 이 PC 에서는 내 것이 먼저 보입니다([원래대로]로 되돌림).

[명령어 변환]
 - 아는 명령어를 넣으면 같은 일을 하는 다른 벤더 명령어를 보여 줍니다. 줄임말(sh run, conf t, wr)과 프롬프트(Switch#, ->)도 됩니다.
 - 여러 줄을 붙여 넣어도 됩니다 (예: interface gi1/0/5 + switchport access vlan 10).
 - 포트·MAC·마스크 값을 다른 벤더 형식으로 바꿔 채웁니다. 포트 이름 형식은 [설정] → 포트 이름 에서 바꿉니다
   (스택 2번이면 시스코 GigabitEthernet2/0/, 얼라이드 port2.0. 처럼).

[설정 만들기]
 - VLAN, 포트(access/trunk), LACP, 관리 IP·게이트웨이, NTP·로그 서버·SNMP·SSH 를 넣으면 벤더별 설정문을 만듭니다.
 - 포트는 앞판 번호로 넣습니다 (1-20, 24). 주니퍼는 0부터라 1번 = ge-0/0/0 으로 바꿔 넣습니다.
 - 비밀번호는 <비밀번호> 로 비워 두니 실제 값으로 바꿔서 넣으세요.
 - 넣기 전에 꼭 읽어 보고, 랩이나 콘솔로 붙은 장비에서 먼저 시험하세요.

[내 명령어]
 - 현장에서 자주 쓰는 명령어를 넣어 두면 사전·검색·변환에 같이 나옵니다.
 - [내보내기] 파일로 다른 PC 에 옮기고 [가져오기]로 합칩니다.

[업데이트]
 - 시작할 때와 하루 한 번 새 버전을 확인합니다([설정]에서 끌 수 있음). 설치판은 [받아서 설치]로 업데이트됩니다.
 - 인터넷이 안 되는 PC: 릴리즈 페이지의 OiCmd-update-버전.zip 을 [설정] → 업데이트 → [업데이트 파일로 설치]에 올립니다.
 - 업데이트 파일은 만든 사람의 서명이 맞아야만 설치됩니다.

[보안]
 - 화면은 이 PC 안(127.0.0.1)에서만 열리고, 실행할 때마다 바뀌는 토큰이 있어야 데이터를 읽고 씁니다. 다른 PC 에서는 접속할 수 없습니다.
 - 인터넷은 업데이트 확인에만 씁니다 (github.com).
